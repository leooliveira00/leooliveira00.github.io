## 🗺️ ROADMAP - ORDEM RECOMENDADA

### Dia 1: Instalação e Primeiro Contato
```
1. Leia INICIO_RAPIDO.md (10 min)
2. Siga INSTALACAO.md (10 min)
3. Veja o site funcionando
4. Explore cada seção do portfólio
```

### Dia 2: Customização Básica
```
1. Leia GUIA_CUSTOMIZACAO.md (15 min)
2. Altere informações pessoais (30 min)
3. Adicione seus projetos reais (1-2h)
4. Ajuste habilidades (30 min)
5. Atualize trajetória (30 min)
```

### Dia 3: Imagens e Qualidade
```
1. Leia public/projects/README.md (10 min)
2. Capture screenshots dos projetos (1h)
3. Otimize imagens (30 min)
4. Adicione ao portfólio (30 min)
5. Teste tudo (30 min)
```

### Dia 4: Deploy
```
1. Revise TODO o conteúdo (30 min)
2. Faça build: npm run build (5 min)
3. Deploy no Vercel/Netlify (15 min)
4. Teste online (30 min)
5. Configure domínio (opcional)
```

### Dia 5: Marketing
```
1. Leia GUIA_RECRUTADORES.md (20 min)
2. Atualize LinkedIn (30 min)
3. Atualize GitHub (20 min)
4. Atualize CV (30 min)
5. Prepare email de candidatura (20 min)
```

### Dia 6-7: Candidaturas
```
1. Liste 20+ empresas alvo (1h)
2. Envie 5-10 candidaturas (2h)
3. Configure tracking (30 min)
4. Prepare para entrevistas (1h)
```

**Total estimado: 10-15 horas ao longo de 1 semana**

## 📊 CHEAT SHEET - REFERÊNCIA RÁPIDA

### Comandos Essenciais
```bash
npm install          # Instalar dependências
npm start            # Rodar em desenvolvimento
npm run build        # Build para produção
vercel               # Deploy no Vercel
```

### Arquivos Mais Editados
```
src/data/projectsData.js   → Seus projetos
src/data/skillsData.js     → Suas habilidades
src/data/timelineData.js   → Sua trajetória

src/components/Hero/Hero.jsx      → Links sociais
src/components/Contact/Contact.jsx → Informações de contato
src/components/Footer/Footer.jsx   → Links do rodapé

public/index.html          → Título da página
public/projects/           → Imagens dos projetos
```

### Links Importantes
```
EmailJS: https://www.emailjs.com
Vercel: https://vercel.com
Netlify: https://netlify.com
TinyPNG (otimizar imagens): https://tinypng.com
```
